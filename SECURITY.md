# Security Policy

Wadjet is intended for authorized security testing and education only. Use it
only against systems you own or have explicit permission to test.

To report a vulnerability in Wadjet, email **pyramidsec@gmail.com**. Include a
clear description, affected version or commit, reproduction steps, and any
suggested mitigation. Please avoid including real credentials or sensitive
third-party data in reports.

Do not use the intentionally vulnerable test server outside an isolated local
environment. It binds to loopback only.
